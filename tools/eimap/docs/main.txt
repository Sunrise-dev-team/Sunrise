EIMap tool

Программа для работы с картами, поддерживает перегенерацию тайлинга, установку новой карты высот и другие возможности.



Использование:
<имя карты> - название .eimap файла
<mapname> - имя для всех выходных файлов, заданное в .eimap

Для запуска программы необходимы следующие файлы, все кроме .eimap юерутся из папки sources программы:

<имя карты>.eimap - (обязат!) файл с описанием карты и её материалов, передаётся в качестве аргумента программе. Формат файла описан отдельно (см. eimap_format.txt)

<mapname>.mpr - (обязат!) в файле допустима карта больше или равная в секторах карте высот или карте тайлинга, в ином случае возможны неполадки в работе.

<mapname>_pal.png - (обязат!) палитра для соответствия материала из eimap по индексу с цветом на карте тайлинга. Размер: 1x32, не используйте чёрный (0,0,0,255) цвет между цветами материалов, потому что при его обнаружении дальнейшие материалы не считываются!

<mapname>_tiles.png - (обязат!) карта тайлинга. Составляет x0.5 + 1 относительно карты высот, каждый пиксель соответствует применяемому на углу (четверти) тайла материалу. Не используйте цвета, отсутствующие в палитре!

<mapname>_water_tiles.png - тайлинг для водного слоя. Аналогично карте тайлинга, только допустим чёрный (0,0,0,255) цвет для обозначение тайлов без воды. Материалы на этом слое крайне желательно должны иметь submat (см. eimap_format.txt)

<mapname>_height.png - карта высот. Каждый пиксель соответствует одному вертексу (вершине) ландшафта. Значение берётся из канала R (красный), при этом допучтимо ч/б изображение.

<mapname>_water_height.png - карта высот для водной поверхности. Каждый пиксель соответствует одному вертексу (вершине) ландшафта. Значение берётся из канала B (синий), при этом допучтимо ч/б изображение.

После успешного выполнения программы в папке output появяются файлы <mapname>.mpr и <mapname>.yaml - изменённый файл карты и атлас для генерации в ei-hd-tiles.
Так же программа при завершении запускает модифицированный ei-hd-tiles в папке eht_builder, в результате работы которого добавляется ещё <mapname>.res со сгенерированными и упакованными в игровой формат атласами, и <mapname><index>.png файлы со сгенерированными атласами, которые можно использовать в EIMapPainter`е.
