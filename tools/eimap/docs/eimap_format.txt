 *.eimap : EIMap.exe format
Содержит определения для карты, материалов для водной поверхности и материалов в палитре.

Построчно интерпретируемый формат, порядок строк важен в отдельных случаях.
Разделителем является пробел, по этому недопустимы пути и ключевые слова с этим символом.
Формат чувствителен к регистру, все ключевые слова пишутся в snake_case.
Строки, начинающиеся с '// ', являются комментариями.

str - допустимы любые символы, кроме пробела.
int - допустимы числа со знаком.
float - допустимы числа со знаком и дробной частью (разделитель ',')
arr - допустима последовательность элементов, разделённая пробелом; в этой строке недопустимы комментарии!
enum - допустимы особые значения.

Обязательность (обязат!) полей отмечене относительно родительских полей (есть #mat - пиши и #tiles).



// #######################################################
// Основные опции (Header)
// #######################################################

#mapname <имя_файла: str> - (обязат!) имя вводного .mpr, и имя выходных .mpr + .yaml + .mmp

#maxunique <число: int> - предельное количество вариаций для полных, угловых, диагональных и половинчатых двухматериальных тайлов

#seed <число: int> - (обязат!) зерно значений для рандома; при сохранении остальных вводных, изменяет результат.

#maxz <число: float> - модификатор высоты, влияет на карту высот

#smooth <сила: float> (<предел разницы высот: float>) - незначительное сглаживание ландшафта. Сила: Значение от 0 до 1.2, отрицательные - не применять; Предел высот: при превышении его пары вершин не сглаживаются относительно друг друга. Для обрывов и границ карты. Могут требоваться достаточно большие значения (1000, 3000). По умолчанию - 1000



// #######################################################
// Материалы для палитры (Materials)
// #######################################################

#mat <индекс_в_палитре: int> - (обязат!) новый материал (все последующие параметры используются в нём)

#masks <угол: str> <половина: str> <диагональ: str> - маски, используемые при наложении материала на низлежащие; при отсутствии берутся соотв. из masks, т.е. masks/half, masks/corner, иначе masks/<путь>

#tilepath <путь: str> - путь к изображениям тайла, обязательн оканчивается на '/'; при отсутствии файлы берутся из tiles, иначе tiles/<путь>

#tiles <имена_файлов: str, arr> - (обязат!) имена изображений тайлов, минимум 1; для водных - рекомендуется только 1

#tiletype <id_вида: str, enum> - Используется для звуков и скорости передвижения по тайлу. Значения: undefined, grass, ground, stone, sand, rock, field, water, road, snow, ice, drygrass, snowballs, lava, swamp, highrock, last; стандартное значение - ground.

#anim <количество_кадров: int> - последовательно вставляет тайлы с числовыми индексами, т.е. <tilepath>/2,<tilepath>/3 и т.д.

#submat <id: int> - указывает какой графический материал используется.



// #######################################################

#definesubmat <id: int> - новый графический материал

#color <формат: str, enum> <r: int> <g: int> <b: int> (<a: int>) - (обязат!) задаёт цвет материала. Формат: rgba, rgb; RGBA компоненты задаются от 0 до 255

#illumination <светимость: float> - (обязат!) самосветимость материала

#wave <значение: float> - (обязат!) 

#warp <значение: float> - (обязат!) 

#type <тип_материала: str, enum> - (обязат!) Тип: terrain, invisible_water, grass, water
